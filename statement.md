=========== STUDENT MARKS AND ATTENDANCE =========

1. problem statement:
                     Managing student details, marks, and attendance manually can be time-consuming and may lead to errors. 
                     This project provides a simple console-based system to store and manage student information, calculate results, track attendance, and save records in a CSV file.

2. SCOPE OF THE PROJECT :
                         The project focuses on basic student management,marks calculation,
                          attendance tracking, result generation, and CSV file storage.

3. TARGET USER: 
               A. student
               B. Teachers
               C. Faculty members
               
               
4. HIGH LEVEL FEATURES:
                       1. Add student details
                       2. earch student by roll number
                      3. Update student information
                      4. Delete student records
                       5. Enter marks and attendance
                       6. Calculate total and percentage
                       7. Generate grades
                       8. Calculate attendance percentage
                       9. Check attendance eligibility
                       10. Save student data to CSV
                        11. Check CSV file availability
